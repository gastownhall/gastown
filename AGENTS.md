# Agent Instructions

Run `gt prime` after a new session, compaction, or context reset. It renders the
active Gas Town identity, assignment, and role-specific operating context.

This tracked file is a compatibility index for providers that discover
`AGENTS.md`; it is not a second lifecycle runbook. Keep command behavior and
lifecycle details in the product documentation:

- [Polecat lifecycle](docs/concepts/polecat-lifecycle.md)
- [Epic integration branches](docs/concepts/integration-branches.md)
- [Convoys](docs/concepts/convoy.md)
- [Fork-backed rigs](docs/guides/fork-rig-setup.md)
- [CLI and configuration reference](docs/reference.md)
- [Release process](RELEASING.md)

Provider-specific `CLAUDE.md` files and role context rendered by `gt prime` are
generated projections. Change their template owners, then regenerate; do not
edit the projections in place.
